# ai-ground-robot-target-mapping
EE426/EE430 project for YOLO-based visual detection and GPS-assisted mapping of simulated surface targets using a ground robot.


Project Overview

This project investigates the feasibility of a small ground-robot system that uses a YOLO-based computer-vision model to detect predefined simulated surface targets and associate detections with approximate GPS positions.

The intended system includes camera-based object detection, basic waypoint navigation, obstacle response, target-position recording, and a simple visualization of detected targets.

The prototype is intended for academic research and controlled experiments using safe simulated or inert targets. It is not intended for real-world mine detection, explosive handling, or deployment in hazardous areas.

Project Objectives

Define the system requirements and functional specifications.

Evaluate suitable hardware and software technologies.

Design the system architecture and investigate feasibility through modelling and simulation.

Prepare a labelled dataset and evaluate a YOLO-based detection model.

Develop and evaluate navigation, position-recording, and mapping functions.

Document the implementation and experimental results.

Safety and Scope

All experiments will use safe simulated or inert surface-visible targets in a controlled environment. The project excludes real explosives, buried-mine detection, mine clearance, and operation in hazardous areas.

Project Stages

EE426 — Design Project I: requirements, technology selection, system design, modelling, simulation, and proposal.

EE430 — Design Project II: hardware implementation, integration, laboratory testing, optimization, and final documentation.
